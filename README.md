# Terraform Starter

Terraform exercises covering Infrastructure as Code skills using AWS. Including: infrastructure configuration, resource dependencies, iteration with for_each, reusable modules, remote backend, and state management.

Labs based on Bryan Krausen's Terraform **hands-on material, completed as part of my preparation for the HashiCorp Certified: Terraform Associate (004) certification.**

## Labs

| Lab | Focus |
| --- | ----- |
| [01–05 — Foundations](01-05-foundations/) | AWS infrastructure provisioning, resources, variables, outputs, and dependencies |
| [09 — for_each](09-for-each/) | Using `count` versus `for_each` to manage multiple resources |
| [15 — Local Modules](15-local-modules/) | Organizing infrastructure into reusable modules |
| [20 — Remote Backend](20-remote-backend/) | Configuring S3 remote state storage and exploring state management |

## Tools

Terraform CLI · AWS · HCL · VS Code · Git/GitHub
